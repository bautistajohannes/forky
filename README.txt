# Invitación digital — Luccas Alejandro

## Estructura

- `index.html` → estructura de la invitación.
- `style.css` → diseño, colores, animaciones y versión móvil.
- `config.js` → **archivo principal que debes editar**.
- `script.js` → funciones interactivas.
- `images/` → fotografías.
- `music/` → música.

## Personalización rápida

Abre `config.js` y modifica:

- `cumpleanero`
- `edad`
- `fechaTexto`
- `fechaISO`
- `horaTexto`
- `lugar`
- `mapsUrl`
- `whatsapp`
- `tema`
- `fotoPrincipal`
- `fotos`
- `musica`

## Fotografías

Coloca tus imágenes en:

`images/foto-principal.jpg`
`images/foto1.jpg`
`images/foto2.jpg`
etc.

## Música

Coloca tu canción en:

`music/cancion.mp3`

Luego cambia el nombre en `config.js` si utilizas otro archivo.

## Publicación

Estos archivos pueden subirse directamente a un repositorio de GitHub y publicarse mediante GitHub Pages.
